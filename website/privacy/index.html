XpandMax’s follower-count extension processes information locally. It does not send account data to us. Local translation is the default; optional Google or custom API translation sends bio text to the provider you choose.

Last updated: October 15, 2026

The extension

XpandMax runs only on https://x.com/* and https://twitter.com/*. It observes the same-origin GraphQL responses already loaded by the page, extracts account handles, follower counts, bios and self-reported profile locations, plus following, pending-request and blocking states needed for the follow button, and reads account-name elements so it can display matching labels, compact bio excerpts below post authors, with full bios and self-reported locations on expansion.

These fields are kept only in the current tab’s memory, with a limit of 5,000 accounts and a separate 30-minute freshness window for each field. Profile locations are entered by users; they are not device locations or verified countries. They are cleared when you refresh or close the tab. A missing count does not mean zero followers.

On supported desktop Chrome versions, foreign-language bios can be translated using Chrome’s built-in on-device models. Chrome may download language packs after you enable translation; in local mode, bio text is not sent to our servers or an external translation API. Up to 500 translations are cached in tab memory for 30 minutes and cleared on refresh or close. Chrome manages its own model files separately.

The storage permission remembers the translation provider, endpoint, model and API key, plus three boolean preferences in chrome.storage.local: hiding the unread number on the notification icon, hiding the left navigation, and hiding the right sidebar. These preferences stay on this device and are not synced to the cloud. No account profiles, follow states, or notification content are stored there. Hiding the badge does not mark notifications as read or process notification content; hiding navigation or a sidebar only changes the local page layout and does not change account or recommendation preferences.

To confirm a follow action, the extension also observes the same-origin responses to X’s native follow, unfollow and cancel-request actions. It does not construct its own follow requests or read authorization headers.

Optional custom translation

When you choose a custom API and grant access to its HTTPS host, the extension background sends bio text, a translation instruction and the configured model and API key to that provider. Handles and URLs are masked where possible, but this is not anonymization. X cookies and login tokens are never included. The provider sees your IP address, may retain requests under its own policy and may charge for them. The connection test sends only “I build useful tools.” No public key or free quota is included.

API settings stay on this browser without cloud sync. The key is stored locally, not in a password vault. Saving local translation clears the API configuration and stops new online requests; changing configuration aborts in-flight local requests and frees their slots, but data already received by a provider cannot be recalled. Previously granted host access can be revoked in the browser’s extension settings. Translations remain in tab memory, and changing settings clears that cache.

The optional Google no-key mode sends bio text to https://translate.googleapis.com/translate_a/single, without cookies or an API key. Google receives the text and your IP address under its own privacy policy. This endpoint has no formal service guarantee and may be limited or discontinued; ongoing free access is not guaranteed. Saving Google mode clears saved custom API credentials.

Validation scope

Google no-key mode and Gemini through AIGoCode were tested with the unpacked extension in EGO. Anthropic Messages and Chat Completions currently have mocked automated test coverage only, not live provider verification. This is not certification of every provider.

What we do not collect

  • No X cookies, passwords, or request authorization headers are read by the extension. An API key entered in translation settings is stored locally and used only for the configured translation service.
  • No extra account API requests are made.
  • No account profiles or page responses are written to browser storage. When online translation is enabled, the selected provider receives bio text and handles it under its own policy.
  • No analytics, advertising SDKs, or remotely loaded code are included in the extension.
  • A real user click on the follow button activates X’s own follow menu item for that post author. The extension does not automatically follow accounts, unfollow, like, post, or send direct messages.

Site access

Chrome may describe the extension’s access as reading and changing data on X. This is needed to match account information and insert labels. The extension does not request cookie, history or download access. Its manifest declares optional HTTPS access to support custom API hosts; saving online translation requests access only to the Google translation host or the configured custom host, not all sites. Content scripts still run only on X.

Page-to-extension messages are used only to display account context. X can affect the underlying data and page structure, so the labels are a browsing aid, not an identity-verification or audit service.

This website

This website has no account system, contact form, analytics scripts, or advertising cookies. It is hosted on Vercel, which processes standard request information, such as IP address, browser information, and access time, to serve and secure the site. This hosting is separate from the extension’s local operation.

External links, including links to X, are covered by the destination’s policies. Visiting this website is not required for the extension to function after installation.
