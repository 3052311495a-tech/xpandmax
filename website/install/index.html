Add to Chrome ↗

Install from the Chrome Web Store

  1. Open the Chrome Web Store using the button above.
  2. Click Add to Chrome and confirm the installation.
  3. Open or refresh x.com. Compact follower counts and bios appear below post authors where X provides the data.

The Chrome Web Store version may lag behind the latest build. You may also see the earlier name “X 粉丝数” (X Follower Count). The same extension ID is used for updates. Download v0.9.2 below if you want the latest features now.

Prefer to install the latest build manually?

Download XpandMax 0.9.2 as a ZIP for desktop Chrome 111 or newer. Extract it to a folder you’ll keep. Open chrome://extensions, turn on Developer mode, click Load unpacked, and select the extension folder inside the download. Then refresh X.

Manual installs do not receive automatic Chrome Web Store updates. Disable any other copy of the extension first to avoid duplicate labels.

What’s new in v0.9.2

  • A compact author line: blue follower count, a follow button, and a short bio.
  • Click the count or bio to expand the full profile details. Foreign-language bios can be translated into Chinese locally in supported Chrome versions.
  • Click Follow once to follow an author through X’s own interface. The button is not shown for authors you already follow.
  • The notification bell’s unread number is hidden by default. Open the XpandMax toolbar popup to turn it back on.

A little context

What if I already have the old X Follower Count extension?

If you installed from the Chrome Web Store, keep it installed: the brand update uses the same extension ID and will be delivered through the store after approval. For a manual install, remove or disable the old unpacked copy before loading XpandMax.

Why is a follower count missing?

XpandMax only displays data X has already returned to your page. A dash means the count is not available, not that the account has zero followers. Refresh after installing. Counts are snapshots and may differ from a live profile.

What access does the extension need?

It runs on x.com and twitter.com to read the account information already loaded and show compact author details. The storage permission remembers optional translation API settings (including the key) and three on-device preferences: hiding notification counts, the left navigation, and the right sidebar. Account profiles and follow states are not stored, and these settings are not synced to the cloud. It does not request cookie or browsing-history access. Custom API translation optionally requests access to the HTTPS host you configure and sends bio text there; it is off by default. Read the privacy policy.

Will it work on every X page?

It supports common desktop feeds, replies, profiles, search results, and account lists where X provides follower data. X can change its interface or response format, so some views may need a future update. Mobile browser installation is not supported.
